# Parth Restaurant 
A visually immersive and fully responsive restaurant website built using **HTML, CSS, and JavaScript**, designed to deliver a premium dining experience online through elegant UI/UX, smooth animations, and interactive functionality.

This project combines aesthetic design with practical restaurant features such as **table booking, digital menu browsing, chef introduction, contact information, and featured dishes**, making it ideal for modern restaurants, cafés, or hospitality businesses.

---

## Overview

In today’s digital-first world, a restaurant’s online presence plays a major role in attracting customers and driving reservations.

FineDine was created to provide a seamless and engaging digital dining experience where users can:

- Explore the restaurant visually
- Browse the full menu
- View featured chef specials
- Learn about the restaurant and chef
- Book a table online
- Contact the restaurant easily
- Experience smooth modern animations

The project focuses heavily on **clean design, premium aesthetics, responsiveness, and intuitive navigation**.
